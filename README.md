# 🧊 SmartFridge — персональный помощник на кухне

**SmartFridge** — веб-приложение на Java и Spring Boot для управления продуктами, рецептами и рационом питания.

Приложение позволяет вести собственный «умный холодильник», отслеживать количество продуктов, подбирать рецепты на основе доступных ингредиентов, рассчитывать калорийность и БЖУ, сохранять понравившиеся блюда и вести календарь питания.

Проект разработан в рамках **дипломной работы**.

## 🚀 Основные возможности

### 🔐 Аутентификация и авторизация

* регистрация и вход пользователей;
* JWT-аутентификация;
* авторизация с использованием Spring Security;
* разграничение доступа к пользовательским данным.

### 🥒 Умный холодильник

Пользователь может вести список продуктов, которые находятся у него в наличии.

Для каждого продукта хранится:

* название;
* количество;
* единица измерения;
* дата добавления;
* калорийность;
* содержание белков, жиров и углеводов.

Продукты автоматически приводятся к единому виду. Например, различные варианты названия одного продукта могут быть нормализованы до общего представления.

Информация о пищевой ценности используется далее при расчёте калорийности рецептов и записей о потреблении.

### 🍳 Рецепты

Пользователь может:

* просматривать доступные рецепты;
* создавать собственные рецепты;
* указывать ингредиенты и их количество;
* задавать категорию и количество порций;
* просматривать состав блюда;
* добавлять рецепты в избранное;
* добавлять блюда в календарь питания.

Для каждого рецепта рассчитывается пищевая ценность:

* общая калорийность;
* белки;
* жиры;
* углеводы;
* значения на одну порцию.

### 🧠 Подбор рецептов

Приложение позволяет находить рецепты на основе продуктов, которые уже есть в холодильнике.

Это позволяет использовать приложение не только как справочник рецептов, но и как инструмент для планирования приготовления блюд из имеющихся продуктов.

### ❤️ Избранное

Пользователь может добавлять рецепты в избранное и быстро получать к ним доступ через отдельный раздел.

### 📅 Календарь питания

Календарь позволяет фиксировать фактическое употребление продуктов и блюд.

Для каждой записи можно указать:

* продукт или рецепт;
* количество;
* дату употребления;
* необходимость списания соответствующих продуктов из холодильника.

Для выбранного дня рассчитываются суммарные показатели:

* калории;
* белки;
* жиры;
* углеводы.

Таким образом, приложение объединяет управление запасами продуктов с ведением дневника питания.

### 🔍 Полнотекстовый поиск

Для поиска используется **Elasticsearch**.

Поиск поддерживает:

* поиск по рецептам;
* поиск по продуктам;
* русскую морфологию;
* словарь синонимов;
* поиск по названиям и ингредиентам.

Например, различные формы слова или синонимы могут быть сопоставлены с одной сущностью:

`огурчик` → `огурец`
`корнишон` → `огурец`

Это позволяет получать более релевантные результаты без необходимости вводить точное название продукта или рецепта.

## 🛠️ Технологии

| Технология            | Назначение                   |
| --------------------- | ---------------------------- |
| **Java 17+**          | Язык реализации              |
| **Spring Boot**       | Backend-фреймворк            |
| **Spring Security**   | Аутентификация и авторизация |
| **JWT**               | Авторизация запросов         |
| **Spring Data JPA**   | Работа с реляционной БД      |
| **PostgreSQL**        | Основная база данных         |
| **Flyway**            | Миграции базы данных         |
| **Elasticsearch**     | Полнотекстовый поиск         |
| **Swagger / OpenAPI** | Документирование REST API    |
| **Gradle**            | Система сборки               |

## 📌 Ключевые особенности проекта

* авторизация пользователей и защита пользовательских данных;
* проектирование реляционной модели данных;
* работа с PostgreSQL и JPA;
* миграции базы данных;
* полнотекстовый поиск через Elasticsearch;
* настройка русской морфологии и синонимов;
* расчёт калорийности и БЖУ;
* подбор рецептов по имеющимся продуктам;
* учёт остатков продуктов;
* списание продуктов при употреблении;
* календарь питания и расчёт дневных показателей;
* REST API с документацией через Swagger/OpenAPI.

## 🎓 О проекте

Проект разработан в рамках **выпускной квалификационной работы**.

Основная задача проекта — разработать систему, объединяющую управление продуктами, поиск и подбор рецептов, расчёт пищевой ценности и учёт фактического потребления продуктов.

Особое внимание уделено организации хранения данных, поиску по русскоязычным названиям продуктов и рецептов, а также автоматическому расчёту пищевой ценности.
